# 穿画转场视频（组员1）

放置文件：

```text
public/videos/ink/enter-painting.mp4
```

**当前文件是 Day 1 的占位版**：由仓库外的 `make-ink-placeholder.py` 用
`assets/images/qianlijiangshan.jpg` 程序生成的 6 秒推轨动画（1280×720 / 30fps / 约 0.5 MB），
只用于验证「按钮 → 视频 → 四画选择」这条链路。正式版必须由组员1 用 AI 穿画工具重做后替换，
并在下面补齐来源与授权。

要求（见 `docs/current/组员1任务-四画入境.md` §二）：

- 横屏 16:9，建议 4–8 秒，单文件 ≤ 5 MB
- 无小红书界面、无教程字幕、无水印
- 开头从水墨 / 古画局部进入；中段至少两次方向变化或环绕
- 结尾用白雾、墨雾或画纸留白退出，方便接四画选择界面

视频缺失、404 或浏览器拒绝自动播放时，`js/ink-worlds.js` 会自动改用
2.6 秒墨雾占位转场，然后照常进入四画选择，不会黑屏。
