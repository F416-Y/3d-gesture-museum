# 展厅参考图目录

本目录按“当前使用 / 技术依据 / 历史归档”管理。组员优先读取 `current/`；需要尺寸、三视图、结构拆分或零件依据时读取 `technical/`。

## 当前使用

`current/` 放已经按最新约定确认的参考图：桥与中心湖、以及最新展厅内饰稿。当前不把 `generated-area` 的外景宣传图当作建模依据，因为它们没有准确体现桥、湖和建筑的实际关系。后续新稿只进入这里，并使用带版本号的文件名。

## 技术依据

`technical/` 放旧稿中仍有建模价值的内容，尤其是三视图、平面尺寸、结构分解和零件图。它们不是最终视觉方案，但不能删除，建模时用于量尺寸和拆零件。

## 历史归档

`archive/` 预留给完全淘汰、仅供追溯的旧视觉稿。未经确认不要直接删除。

## 同步规则

- 视觉方案以 `current/` 为准。
- 尺寸和零件拆分以 `technical/` 为准；若与 `current/` 冲突，以最新已确认的坐标、尺寸和方向说明为准。
- 新文件名写清区域、视角和版本，例如 `bridge-lake-top-plan-v1.png`。
- 文档引用优先使用本目录的相对路径，避免引用个人临时目录。
