## 二、代码接入点（组员6 相关）

| 位置 | 说明 |
|---|---|
| `js/scene.js` → `addPainting()` | **优先加载 `assets/images/<展品id>.jpg`**，失败回退程序化示意 |
| `js/scene.js` → `tryReplaceWithGlb()` | 通用 glb 加载器；成功→隐藏原几何体，失败→保留几何体（场景不留空白） |
| `js/scene.js` → `addVenusSculpture()` | 维纳斯：展台 + glb + 程序化回退 |
| `index.html` | 引入 `GLTFLoader`（r147 UMD 版）|
