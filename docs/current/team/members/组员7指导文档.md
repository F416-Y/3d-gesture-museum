# 组员 7 指导文档 · 组长

## 先看这里：分支与工作顺序

- 推荐分支：`feature/wenchuang-interior-7`
- 负责 `public/wenchuang.html`、参考图、尺寸/坐标验收，以及 `gate-tower`、`steps`、`camphor`、`bush` 四个指定零件。
- 开始：`git switch main` → `git pull` → `git switch -c feature/wenchuang-interior-7`。
- 建模顺序：先确认参考图与坐标 → 先做 `steps` / `bush` 等小零件 → 再做 `gate-tower` / `camphor` → 最后组合文创内饰 HTML。
- 组长也必须走 feature 分支和 PR；不直接改 `main`，不顺手接管组员 8 的展示架、宫灯 GLB。
- 详细工具链：见 [AI-Blender-Hyper3D建模流程](../AI-Blender-Hyper3D建模流程.md)。

## 负责范围

- 负责参考图生成、整理、尺寸/坐标基准、验收和协调。
- 负责文创内饰页面：`public/wenchuang.html`。该页面由组长单独维护，展示架和宫灯 GLB 仍归组员 8。
- 额外承担 4 个限定零件：`gate-tower`、`steps`、`camphor`、`bush`。
- 参考图目录：`assets/reference/`、`assets/reference/exhibition/`。

## 不负责

- 只允许使用 Blender 建模上述 4 个零件。
- 不制作、修改或导出其他 GLB。
- 除 `public/wenchuang.html` 外，不代替组员编写其他内饰 HTML 或交互代码。

## 操作步骤

1. 根据实际坐标和尺寸生成一张一张确认的参考图。
2. 给每个零件绑定参考图相对路径和 `sizeM`。
3. 按零件总表建模上述 4 个零件，统一 Z-up、原点、底部落地和相对纹理路径。
4. 检查自己和组员提交的 Blender 360° 截图、网页固定机位截图和路径声明。
5. 发现方向、比例、落地、遮挡或拼接错误时退回对应负责人，不扩大自己的建模范围。
6. 文创页面只修改 `public/wenchuang.html`，不得修改组员 8 的 `display-shelf.glb`、`lantern.glb`。
7. 在 PR 中留下验收结论和需要返工的具体项。

## 完成标准

总表里的每个零件都有负责人、路径、状态和验收记录；4 个指定零件完成 GLB、尺寸/原点说明和页面验证，不出现“大家一起做”或“负责人待定”。
