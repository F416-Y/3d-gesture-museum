## 十一、手把手操作教程（组员2）

本节以“先读懂现有代码，再做最小修改”为准。只改漫游、相机和人物模型交接，不修改 index.html、展厅 HTML、桥湖坐标和远景资源。

### 11.1 建立基线

```powershell
git status --short
git switch main
git pull origin main
git switch -c feature/player-third-person-2
rg -n "camera|third|first|collision|player|position|KeyW|KeyS|KeyA|KeyD" js public index.html
```

先把真实入口填下来：玩家状态文件、相机创建位置、键盘事件入口、碰撞入口、重置视角函数、V/T 入口、人物模型加载入口。不要凭文件名猜。

如果工作区有不是自己创建的修改，停止操作并截图，不要 reset、stash 或覆盖。

### 11.2 确认坐标和参数

先确认世界竖直轴、玩家脚底高度、眼睛高度、胶囊半径、最大步高、桥面高度和湖岸边界。项目已有参数优先复用，不要重复造魔法数字。

建议整理成参数表：

```js
const PLAYER_TUNING = {
  eyeHeight: 1.65,
  thirdPersonDistance: 4.2,
  thirdPersonHeight: 2.2,
  capsuleRadius: 0.35,
  maxStepHeight: 0.25,
  moveSpeed: 2.4,
  turnSpeed: 1.8
};
```

实际数值必须以现有项目单位和场景测试为准。

### 11.3 第一/第三人称切换

1. 找到当前第一人称相机和渲染循环。
2. 增加明确模式状态，例如 `viewMode = 'first'`。
3. T 键切换第三人称，V 键保留项目原有含义。
4. 切换时保留玩家位置和水平朝向。
5. 第三人称相机放在玩家后上方，并做墙体遮挡检测。
6. 切回第一人称时恢复眼睛高度。

目标关系：

```text
目标点 = 玩家位置 + 眼睛/肩部高度
相机位置 = 玩家后方距离 + 上方高度
若相机与目标点之间有墙体 → 把相机推到墙前
每帧平滑追踪，不瞬移、不抖动
```

不要新增一套与项目现有相机互相竞争的系统。

### 11.4 W/S/A/D 漫游

1. W 沿当前朝向前进，S 后退。
2. A/D 按项目现有约定转向，不擅自改成横移。
3. 使用 deltaTime，不能受刷新率影响。
4. 移动前做碰撞/地面检测，移动后校正高度。
5. 上桥时脚底贴桥面，离桥不能继续走进湖面。
6. 进入室内时不穿墙、不穿地板。

排错顺序：先 W/S，再 A/D，再碰撞，再第三人称跟随；每次只改一个问题。

### 11.5 固定场景验收

| 区域 | 操作 | 必须看到 |
|---|---|---|
| 前庭地面 | W/S 往返 | 脚底贴地 |
| 建筑墙面 | W 直撞 | 玩家停住 |
| 门口 | W 进入/退出 | 不被门框卡住 |
| 桥头 | W 前进 | 能从近岸上桥 |
| 桥面 | W 通过 | 高度连续 |
| 湖岸 | W 靠近 | 有边界，不走入湖 |
| 室内 | W/S/A/D | 不穿墙、不掉地 |

记录页面、坐标、朝向、按键、现象和截图；不要为修碰撞点修改桥湖模型。

### 11.6 人物模型筛选与交接

组员2负责找模型、核对授权和提供接入参数，不负责替其他成员做大型建模。

筛选顺序：

1. 确认授权可用于课程项目。
2. 优先选择低面数、站立姿态、比例正常、格式稳定的模型。
3. 在预览工具或 Blender 中确认正面、竖直轴、脚底和包围盒。
4. 记录身高、宽度、原点、朝向、格式和纹理数量。
5. 把模型或下载地址交给接入负责人，不直接塞进公共场景。

交接表必须写：

```text
模型名称：
来源 URL：
授权/许可证：
文件格式：
实际尺寸：身高__m，宽__m，深__m
原点位置：
正面方向：
最低点是否落地：
贴图数量与总大小：
建议缩放：
交接路径：
接入负责人：
状态：ready / needs-blender-check / blocked
```

没有 Blender 时，不要声称完成模型清理；只能交付来源、预览截图和已知尺寸，并标记待 Blender 复核。

### 11.7 AI 辅助方式

先让 AI 阅读，不要直接重写：

```text
请只阅读 js/player.js 和它实际调用的相机/碰撞文件。
不要改代码。列出玩家状态、两种相机、W/S/A/D、碰撞、地面高度和重置视角的真实函数名与调用关系。
信息不足时明确指出缺失文件，不要猜路径。
```

确认入口后再要求最小补丁：

```text
只实现 T 键第一/第三人称切换。
保留玩家位置、水平朝向、现有 W/S/A/D 和手势逻辑。
不修改 index.html、展厅 HTML、桥湖坐标和远景。
先列修改文件，再输出 unified diff，并说明回退方法。
```

每次修改后执行 `git diff --check`，再开页面验证。
