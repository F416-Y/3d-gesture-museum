## 建模步骤

1. 一次只打开一个零件，删除场景中所有无关建筑、相机和灯光。
2. 对照 `parts-manifest.json` 的 `sizeM` 建模或清理，不扩展到建筑结构、远景层和人物大件。
3. 确认 Z-up、正面方向、原点、最低点和材质名称，应用 Rotation/Scale。
4. 导出到 `assets/models/parts/opt/`，文件名按零件负责人总表中的零件 ID 命名；在 Blender 里旋转 360° 检查破面、悬空、倒置和丢纹理。不要把 `<id>` 当作实际文件名。
5. 只在 `public/shuzhai.html` 或任务单指定的文创落位处替换路径、位置、旋转和缩放。

## 页面步骤

书斋页面保持独立文件，门—案—书架主视线成立；展示架和宫灯只由本组员提供模型，文创页面由组长负责整体页面。

## 完成标准

四个零件各有 Blender 360° 截图、尺寸说明、GLB 路径和页面截图；不改 `index.html`、公共 JS 或其他展厅 HTML。

### 11.7 Hyper3D Prompt B：材质

    Keep the result non-plastic, non-glossy and free from fantasy decoration.

文创零件：

    Use a restrained six-sided wooden frame, warm cream fabric panels and subtle red tassels

### 11.8 Blender 清理步骤

每次只打开一个 GLB：

1. 删除相机、灯光、地面、背景和无关物体。
2. 确认单位、Z-up、正面方向和最低接触点。
3. 应用 Rotation 和 Scale。
4. 方凳、石条凳和展示架原点放在底面中心。
5. 宫灯原点放在吊杆连接点或页面约定的悬挂点。
6. 修复翻面、破面、孤立点、重叠面和丢失材质。
7. 家具底面必须贴地，宫灯不能悬挂到错误高度。
8. 检查木材、石材、绢面和发光材质是否符合用途。
9. 纹理改为相对路径，减少无用材质。
10. 旋转 360° 检查正面、背面、底面和顶部。
11. 导出到 assets/models/parts/opt/，使用实际零件 ID 命名。

不要把书斋和文创两个零件合并成一个 GLB，也不要把模型路径写成 C: 或 D: 盘绝对路径。
