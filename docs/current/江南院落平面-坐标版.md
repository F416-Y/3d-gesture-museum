# 江南院落平面 · 坐标定稿 v1

> 归属：组长 · 2026-09-21
> 用途：**《江南文人国画博物馆》方案的唯一坐标依据**——外观（组长）、接缝登记（组员1）、路由落点（组长）、展品数据（组员4）四方共用。
> 名字不变：馆名仍为**云间入墨**，本方案只改空间与展陈。

## 〇、坐标约定

- **1 单位 = 1 米**；x 向东为正，z 向**南**为正 → **北 = −z**
- 沿用现有园区骨架：围墙 x ±44 / z ±44，南门与门楼 z = 42.2，门洞 x ±4.6，中轴道路 5m 宽（x ±2.5）
- **纪律**：下表"区域矩形范围"是**冻结值**（组员1 的 `hallRegions` 与组员4 的 `hall` 字段都依赖它）。外观造型、材质、装饰可自由调，**改矩形范围必须群里先公告**。
