## 阅读顺序

1. 先看本页和 [8人分工](./8人分工-区域零件与内饰.md)，确认负责人和允许修改范围。
2. 建模成员看 [零件负责人总表](./modeling/零件负责人总表.md) 及自己的任务卡，只修改指定零件或内饰 HTML。
3. 改坐标前看 [院落坐标定稿](./scene/江南院落平面-坐标版.md)；改展品前看 [展品落位表](./exhibition/展品落位表.md)。
4. 提交前按 [流程速查卡](./team/流程速查卡.md) 自测，并把截图或验收结论写入对应记录。
