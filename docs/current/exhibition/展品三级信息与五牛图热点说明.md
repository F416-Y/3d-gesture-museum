## 弹窗层级

弹窗改为三个标签页：

1. **基础信息**：作者、年代、形制、馆藏与作品简介。
2. **作品特点**：优先读取 `features`；没有结构化特点的展品，从赏析前两句自动提炼，避免重复。
3. **细节赏析**：展示完整艺术赏析；有局部热点时提示观众点击画中数字。

## 数据结构

```js
{
  id: "wuniutu",
  features: ["作品特点一", "作品特点二"],
  hotspots: [
    {
      id: "ox-left-1",
      label: "左一 · 昂首凝视",
      x: 11,
      y: 42,
      text: "局部赏析文字"
    }
  ]
}
```

- `x`、`y` 为相对图片宽高的百分比坐标，范围 `0–100`。
- `kind: "seal"` 可用于收藏印或题跋热点，按钮显示“印”。
- 热点按钮支持鼠标、键盘与触屏点击。

## 答辩 Demo

```bash
node scripts/record-exhibit-detail-demo.mjs "D:\AI\识图\云间入墨-展品交互Demo.webm"
```

脚本会实际点击三个标签、五个牛身热点和收藏印热点，并输出 WebM Demo。教室电脑视频或声音异常时，可直接播放该录屏证明功能本身已经实现。
## 教室视频与声音问题说明

线上视频文件已通过 HTTP 200 与正确 MIME 类型检查；若教室电脑出现画面不播放、没有声音或播放器兼容问题，应判定为现场设备的编解码、音频输出或自动播放策略差异，而不是功能缺失。答辩时优先播放本页生成的录屏 Demo，并在答辩电脑上提前测试一次音量与播放器。
