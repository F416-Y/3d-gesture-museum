# 组员1任务：穿越画作与四画选择空间

> 负责人：组员1
>
> 工期：3天试点，试点成功后再扩展
>
> 目标：用户点击序厅的“云间入墨”按钮后，穿进一幅水墨古画，在画中沿轨迹穿行并转动几圈，最后退出到“四幅画选择界面”。用户再点击其中一幅画，才开始播放对应的3D画境。

## 一、必须实现的交互流程

```text
现有博物馆序厅 hall0
  → 点击特定按钮“云间入墨”
  → 播放一次统一的古画穿越视频
  → 镜头沿手绘轨迹进入古画，在画中绕行/转动几圈
  → 视频结束，退出到四幅画选择空间
  → 点击其中一幅画，例如《千里江山图》
  → 开始播放该画对应的3D画境
  → 点击“返回博物馆”回到序厅
```

注意：

- 视频转场不是点击某幅画后才播放。
- 视频的作用是把用户从博物馆带到“四画选择空间”。
- 四幅画选择空间是第二层入口。
- 点击具体画作后，才进入对应的3D画境。
- 第一阶段只真正制作《千里江山图》3D画境，另外三幅先做选择卡和占位状态。

## 二、参考视频与需要提取的方法

组长提供的视频：`763b6c4d593e2bec41da9bcf50bcc917.mp4`。

视频内容是“小红书 AI 线控运镜”教程，核心方法是：

1. 上传一张古画。
2. 在画面上画一条镜头运动轨迹和箭头。
3. 用提示词要求镜头沿轨迹进入古画。
4. 让镜头在画内穿过山水、楼阁、云雾，并进行几次转向或环绕。
5. 结尾离开画面，接到下一个界面。

我们只借鉴“穿越古画的运镜方法”，不要把教程录屏、小红书界面、字幕或水印放进项目。

最终视频要求：

- 横屏 16:9。
- 建议 4–8 秒，先完成一段即可。
- 无小红书界面、无教程文字、无水印。
- 开头从水墨或古画局部进入。
- 中段至少有两次方向变化或环绕，让用户明显感到“穿越画作”。
- 结尾用白雾、墨雾或画纸留白退出，方便接入四画选择界面。
- 单文件尽量控制在 5MB 内。

## 三、第一阶段只做什么

### 必做

- 序厅 `hall0` 增加一个“云间入墨”按钮或交互热点。
- 点击按钮后播放一段穿越古画视频。
- 视频播放期间暂停玩家移动和手势漫游。
- 视频结束后显示四幅画选择界面。
- 四幅画选择界面显示：
  - 《千里江山图》
  - 《富春山居图》
  - 《韩熙载夜宴图》
  - 《墨兰图》
- 点击《千里江山图》后进入第一个3D画境。
- 3D画境至少包含青绿山体、楼阁、云雾三类元素。
- 有“返回博物馆”按钮，回到序厅。

### 暂不做

- 不为四幅画分别制作四段穿越视频。
- 不在第一阶段制作另外三个完整3D世界。
- 不把四幅画直接塞进山水厅、花鸟厅或人物厅。
- 不重写现有手势识别、展品弹窗和地图逻辑。
- 不做复杂自由漫游、任务系统或多层传送门。

## 四、入口和画境位置

### 入口按钮：序厅 `hall0`

建议把“云间入墨”按钮放在序厅中央铜鼎之后或影壁前的空地，使用悬浮墨笔、墨门或墨迹圆环作为视觉标志。

入口只需要一个独立交互点，不新增大规模建筑，也不改变现有展厅碰撞体。

### 四画选择空间

四画选择空间是一个独立的水墨中转界面，可以先用全屏UI实现，不必马上建完整3D建筑。视觉建议：

- 黑白宣纸背景
- 淡淡墨雾
- 四幅画卷或四张悬浮画卡
- 鼠标点击和手势捏合都可以选择

### 四幅画的主题展厅归属

| 画作 | 主题展厅归属 | 3D画境方向 |
|---|---|---|
| 《千里江山图》 | `hall1` 山水厅 | 青绿群山、楼阁、瀑布、云海 |
| 《富春山居图》 | `hall1` 山水厅 | 江面、渔舟、远山、村落 |
| 《韩熙载夜宴图》 | `hall3` 人物厅 | 屏风、灯笼、夜宴、人物剪影 |
| 《墨兰图》 | `hall2` 花鸟厅 | 兰草、山石、留白、墨雾 |

这些展厅只是内容归属和返回锚点，不是第一阶段要重新建造的四个建筑。

## 五、AI穿画视频提示词

### 首帧图基础词

```text
Chinese ink painting, sumi-e, traditional brush,
negative space, xuan paper, misty atmosphere,
ink wash gradients, expressive brush strokes,
classical Chinese painting composition,
no modern objects, no text, no watermark
```

### 《千里江山图》首帧追加词

```text
green mountains, layered peaks, waterfalls,
ancient pavilions, bridges, distant towers,
misty clouds, vast negative space,
青绿山水与水墨交融，镜头入口朝向远方楼阁
```

### 视频运镜提示词

```text
The camera follows the hand-drawn path and enters the ancient Chinese painting.
Move smoothly through the mountains, clouds, water and pavilions.
The camera changes direction twice and makes a gentle circular movement around
the distant pavilion, creating the feeling of traveling inside the painting.
Ink strokes and mist flow naturally while the original painting composition stays recognizable.
At the end, the camera exits through white paper and black ink mist,
leaving a clean bright frame for the next interface.
No sudden cuts, no modern objects, no text, no watermark, no distorted architecture.
```

轨迹建议：

```text
远山入口 → 山谷 → 水面 → 楼阁 → 环绕楼阁 → 墨雾退出
```

不要把轨迹画得过长。先保证镜头能稳定完成一条路径，再增加第二次转向。

## 六、代码接入方案

建议新增：

```text
js/ink-worlds.js
css/ink-worlds.css
public/videos/ink/enter-painting.mp4
```

### 1. 点击按钮

在 `js/ui.js` 增加“云间入墨”入口，点击后调用：

```js
window.MuseumInkWorlds.openPaintingGate();
```

入口应放在 `hall0` 语义下，不要绑定到已有展品的捏合/E键查看逻辑。

### 2. 播放统一穿画视频

`js/ink-worlds.js` 负责：

- 显示全屏视频层
- 播放 `./videos/ink/enter-painting.mp4`
- 暂停玩家移动和手势漫游
- 提供“跳过入画”按钮
- 视频结束后打开四画选择界面
- 视频加载失败时直接打开四画选择界面

伪代码：

```js
function openPaintingGate() {
  pauseMuseumControls();
  showTransitionVideo("./videos/ink/enter-painting.mp4");
}

function onTransitionEnded() {
  hideTransitionVideo();
  showPaintingPicker();
}
```

### 3. 四画选择

四画选择界面先做成独立 overlay，不要先做复杂3D空间：

```js
function selectPainting(id) {
  hidePaintingPicker();
  if (id === "qianli") {
    enterInkWorld("qianli");
  } else {
    showComingSoon(id);
  }
}
```

### 4. 千里江山3D画境

新增或复用 Three.js 的 `THREE.Group`：

```js
const qianliWorld = new THREE.Group();
```

最低内容：

- 远近三层山体
- 一座可辨认的楼阁或亭台
- 一条水面或墨色路径
- 雾效/粒子
- 一个固定的进入镜头
- 一个返回序厅按钮

第一版不要求玩家在画境中长距离行走；如果时间不足，用自动镜头播放加返回按钮即可。

## 七、三天执行计划与止损线

### 第1天：按钮 → 穿画视频 → 四画选择

- 在序厅放入“云间入墨”按钮。
- 用占位视频先验证播放层。
- 完成“视频结束 → 四画选择界面”。
- 四张卡片先可以使用现有名画缩略图。

止损线：第1天结束仍不能完成这条链路，就停止制作3D画境，只保留按钮、穿画视频和四画选择界面。

### 第2天：点击《千里江山图》 → 3D画境

- 点击《千里江山图》后进入 `qianli`。
- 做山体、楼阁、墨雾三个核心元素。
- 加入自动镜头或简单漫游。
- 增加返回序厅按钮。

止损线：第2天结束仍不能稳定进入3D画境，就取消自由漫游，改成固定镜头展示或直接传送到现有 `hall1` 山水厅。

### 第3天：完整演示和验收

- 完成：

```text
按钮 → 穿画视频 → 四画选择 → 千里江山3D画境 → 返回序厅
```

- 检查视频播放失败时的降级。
- 检查原有手势、展品弹窗、地图和昼夜切换不受影响。
- 运行：

```bash
npm run build
node scripts/smoke-scene.mjs
```

止损线：第3天无法完成完整闭环，不扩展另外三个3D世界，只交付稳定的穿画转场和四画选择入口。
