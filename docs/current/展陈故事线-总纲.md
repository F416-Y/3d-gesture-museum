# 展陈故事线 · 总纲（2026-10-09）

> **一句话**：一座江南园林里的中国画观看课 —— 从器物到山水、从格物到入世，最后在对话院与西方艺术互看一眼。
> **展线**：南门 → 序厅（器物与园林）→ 中轴南院影壁 → 中轴双廊画廊 → 山水厅 → 花鸟厅 → 人物厅 → 书斋 · 茶室 → 文创 · 临摹 → 东长廊 → **中西对话院**

## 三、观众一定会记住的三个瞬间（故事线的锚点）

1. **序厅大踏跺上北望影壁「清泉石上流」** —— 园林教你"看"（还有寻杖栏杆凭栏、筒车水院的水轮）
2. **中轴双廊按 E** —— 一廊九画、按一下弹出鉴赏卡：从"看"到"读"（作者 / 年代 / 形制 / 馆藏 / 赏析）
3. **对话院里对望** —— 同一问题两种回答：从"读"到"想"

## 五、项目自身的故事线（工程侧，视频"项目介绍"用）

1. **起点**：外协 Kimi 的《江南文人国画博物馆 · 建筑外观布局原型》——一份可交互原型，定下"门廊同轴 / 照壁实心 / 水景居中"等园林法则
2. **落地**：组长把原型整块搬进项目（`scripts/vendor-prototype.mjs` 自动同步），再逐层接线：真模型替换 → 室内布展 → 画廊真画 → 格扇窗 → 昼夜氛围 → 开场序章
3. **七人分工**：接缝（碰撞体 / 展品热点 / 展厅区域）、漫游与碰撞、手势识别、展品数据与文案、UI 视觉、素材与授权、整合与外观
4. **质量门禁**：语法检查 + 场景冒烟 + 展品全量验收 + 生产构建，全部进 CI；改动一律走分支与 PR，main 只由组长合并
5. **结果**：23 件展品全部可交互、手势断网可用、昼夜灯火、粒子序章、真实俯视地图页
