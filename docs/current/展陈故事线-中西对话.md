# 展陈故事线 · 中西对话（2026-10-09 定稿）

> **定位**：本馆以**中国画为主体**（山水 / 花鸟 / 人物 三厅 + 序厅 + 书斋文创）。西画与西方雕塑**不作主体**，
> 只集中在一个院子里，用「**同一问题，两种回答**」的方式与本馆中国画形成对照。
> **位置**：景观庭院（x 11.5~18 / z −15~−7，与「清泉石上流」影壁同院）→ 本馆称**对话院**
> **展线**：序厅（导览点出三组对话）→ 中国画三厅（hall1 山水 / hall2 花鸟 / hall3 人物）→ 东长廊画廊 → **对话院**（西画对照）

## 一、三组对照（这也是展签与弹窗的文案骨架）

| 组 | 中国画一侧 | 西方一侧 | 共同问题 | 对照点（展签 2~3 句） |
|---|---|---|---|---|
| **肖像** | 韩熙载夜宴图 / 洛神赋图 / 步辇图（hall3） | **蒙娜丽莎** | 怎么画"一个人"？ | 中国画用线造型、以形写神，人物嵌在叙事长卷里，靠姿态与器物说话；文艺复兴用焦点透视与明暗塑造，把人放进一个可测量的空间，靠光与空气说话。 |
| **风景** | 千里江山图 / 富春山居图 / 溪山行旅图（hall1） | **星月夜** | 风景画的是"景"还是"心"？ | 中国山水讲可游可居、讲"卧游"，让观者顺着山径慢慢走进去；《星月夜》把夜空画成旋涡，情绪直接变成笔触的方向与厚度。 |
| **形体** | 将军俑 / 马踏飞燕（hall3 / 庭院） | **米洛的维纳斯** | 为什么残缺仍然美？ | 中国雕塑重"势"与体量感（陶俑的阵列感、青铜的腾跃感）；希腊雕塑重比例与解剖，断臂反而把补全的权力交还给观者。 |

## 二、归属口径（和 9 幅廊道画一致）

- **物理位置**：三件都在**对话院**（景观庭院东侧围栏内，画朝西对着院内；维纳斯在院中）
- **`hall` 字段仍按内容归属**：蒙娜丽莎 → `hall3`（人像）、星月夜 → `hall1`（风景）、维纳斯 → `hall3`（人体）
- 所以**导航栏显示"庭院"、弹窗显示"属于人物/山水展区"是有意为之**，不是 bug（我们全馆都用这个口径）

## 四、展线上的三个落点（谁在哪说什么）

1. **序厅导览牌**：加一行"三组对话：肖像 / 风景 / 形体 → 出东长廊往景观庭院"（可选，导览牌文案由组员4定）
2. **三厅展签**：每组中国画那侧，在弹窗 `appreciation` 末尾加一句"对照提示"，例如溪山行旅图 → "可与对话院的《星月夜》对看：同为'仰望'，一个写山、一个写心"
