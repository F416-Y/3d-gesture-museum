# 云间入墨 · 各组员 Demo 讲稿与录制清单

> 用途：课堂 Demo 分工。每个人只讲自己负责的功能，统一使用项目名称“云间入墨——中国传统绘画数字美术馆”。
>
> 录制标记：
> - **必须额录**：主演示视频里没有清楚展示，需要单独录一段 5–15 秒画面。
> - **可共用**：直接使用主 Demo 对应镜头，不必每个人单独录。
> - **不建议录**：属于工程过程或验收材料，课堂口头说明即可。

## 一、统一开场与顺序

建议顺序：组长总览 → 组员 1 交互入口 → 组员 2 漫游 → 组员 3 山水 → 组员 4 人物 → 组员 5 花鸟 → 组员 6 素材与远景 → 组长收尾。

每个人控制在 **20–30 秒**，先说一句“我负责什么”，再做一个操作，最后说一句“解决了什么问题”。不要把 Git、PR、文件路径讲成主体，除非老师追问。

## 二、逐人讲稿

### 组员 1：四画入境与穿画交互

**讲稿：**

“我负责的是展馆入口到数字画境的交互。用户点击‘入画’后，会先播放水墨转场，再进入四画选择；选择画作后可以进入对应的画境页面。这个功能把传统绘画从墙上的静态展品，变成了可以进入的空间入口。我们还保留了从画境返回展馆的路径，方便继续参观。”

**操作画面：**点击“入画” → 播放水墨转场 → 选择一幅画 → 进入画境。

**录制：必须额录。**需要单独录清楚“点击入画—转场—进入画境”的完整链路，建议 12–18 秒；不要只录转场视频本身。

### 组员 2：漫游、碰撞与视角

**讲稿：**

“我负责的是人在园区里的移动和视角控制。键盘可以用 W、S 前进后退，A、D 转向，也支持第一人称和第三人称观察。移动时会根据场景地面调整高度，并通过碰撞限制避免穿墙、穿柱和悬空，保证观众能沿着园路、台阶和展厅入口正常游览。”

**操作画面：**从序厅或园区出生点前进 → 绕过柱廊/台阶 → 切换一次第三人称或全景视角。

**录制：可共用。**主 Demo 的园区漫游镜头即可；如果第三人称是重点，再额录 8 秒切换镜头。

### 组员 3：山水展厅

**讲稿：**

“我负责山水展厅的独立页面。这个展厅以观看画作为主，采用留白墙面、统一画框和适合正面观看的机位，重点保证画作之间有间距、视线不被柱子或装饰遮挡。用户从园区进入后，可以在独立展厅里集中观看山水作品，再返回园区继续游览。”

**操作画面：**进入山水厅 → 正面展示一组画作 → 左右移动展示无遮挡视线 → 返回园区。

**录制：必须额录。**建议录 10–12 秒固定机位或缓慢横移，重点证明“画作完整、无遮挡、空间留白”。

### 组员 4：人物展厅与立体展品

**讲稿：**

“我负责人物展厅及其中的立体展品陈列。人物厅和山水、花鸟厅不同，除了挂画，还安排了人物类雕塑和青铜器等实体展品。我的重点是让展品之间保持观察距离，入口、底座和标题牌形成清楚的观看关系，观众靠近后可以打开对应的鉴赏信息。”

**操作画面：**进入人物厅 → 展示一件立体展品的正面和侧面 → 靠近展品按 E 打开说明。

**录制：必须额录。**建议 12–15 秒；如果主 Demo 已经有青铜方鼎弹窗，可共用弹窗部分，但人物厅入口和展品全景仍建议单独录。

### 组员 5：花鸟展厅与界面视觉

**讲稿：**

“我负责花鸟展厅的页面呈现，同时参与界面视觉的统一。花鸟厅通过墙面、画作高度、柱廊比例和植物遮挡控制，让画作成为主要视觉焦点；界面上则统一了标题、手势导览、键盘备选和展品弹窗的样式，使不同展厅看起来仍属于同一个博物馆。”

**操作画面：**进入花鸟厅 → 展示画作和柱廊关系 → 打开一次手势导览或展品说明面板。

**录制：必须额录。**建议录 10–15 秒，至少包含一张无遮挡画作和一次 UI 面板展示。

### 组员 6：真实素材、植被与远景

**讲稿：**

“我负责名画、三维展品和植被远景素材的整理与接入。素材不是随意放进场景，而是需要核对来源、授权、比例、原点和落地高度；远景层还要在 360 度转身时连续，不露白、不遮挡建筑。这样既提升了真实感，也保证了素材可以稳定用于课程演示。”

**操作画面：**主 Demo 中缓慢转身展示树木、远山、云雾和画作；若有可用的 Blender 360 度图，可插入一张对比图。

**录制：可共用；素材对比建议额录。**场景转身可直接用主 Demo；如要证明 Blender 优化、授权或 360 度检查，额录 8–10 秒素材检查画面或准备一张截图即可。

## 三、组长收尾稿

**讲稿：**

“我们把项目拆成了场景、漫游、画境、展厅、素材和界面几个模块，最后通过 PR 合并到主线。用户可以从园区进入各个展厅，也可以靠近展品查看信息，点击‘入画’进入四画画境；夜景、真实俯视地图和手势导览则负责补足整体体验。这个项目的核心不是单纯展示模型，而是让中国传统绘画成为一条可以走、可以看、可以进入的数字游线。”

**操作画面：**夜景灯火 → 园区全景 → 片尾项目名。

**录制：可共用。**直接使用主 Demo 收尾镜头；夜景如果仍在调整，先用白天园区全景，不要为了画面完整硬录阴暗夜景。

## 五、统一录制要求

1. 每段开始前留 1 秒静止画面，结尾留 1 秒，方便剪辑。
2. 浏览器全屏、隐藏地址栏和其他标签页；画面统一 1920×1080 横屏。
3. 不要同时录过多功能；一段视频只证明一个功能。
4. 进入展厅的镜头要从园区门口开始，不能直接从展厅内部开场，否则看不出入口关系。
5. 展品弹窗必须等内容完全展开后再停留 2 秒；手势镜头必须看得到摄像头小窗或手势提示。
6. 如果某个页面当前显示“修缮中”或功能尚未联调完成，不能把它写成已完成；用截图和“当前联调状态”说明即可。
