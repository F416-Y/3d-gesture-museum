## 二、推荐素材来源

- **中国传统绘画**：[故宫名画记](https://minghuaji.dpm.org.cn)（**本次采用**，超高清影像）、故宫博物院「[数字文物库](https://digicol.dpm.org.cn)」、[中华珍宝馆](https://www.ltfc.net)
- **三维模型**：Sketchfab（筛 CC0 / CC-BY）、Smithsonian Open Access
- **注意**：任何「仅供学习交流」的图源都不能直接进仓库，宁可先用示意贴图。
- **⚠️ 网络提示**：Wikimedia / 维基系列（含 `upload.wikimedia.org`）与台北故宫（`npm.gov.tw`）在本机网络下**不可达**，请优先使用上述国内站点。
- **⚠️ 下载提示**：故宫名画记的图片托管在腾讯云 COS，**有防盗链**，用命令行下载需带 `Referer: https://minghuaji.dpm.org.cn/`，否则返回 403。

## 三、压缩约定

- 贴图：长边 ≤ 2048px，JPG 质量 80~85，单文件 ≤ 500KB，**场景内实际比例 3:2**
- 模型：glb 单文件 ≤ 5MB（超过再考虑 Git LFS，见 [Git-快速上手.md](./Git-快速上手.md)）
- `assets/` 总大小目标 ≤ 20MB（当前 **1.4MB**）
