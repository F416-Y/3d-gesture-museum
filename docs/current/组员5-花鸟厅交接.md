## 页面交互

- 点击底部“花鸟三品”或直接点击画框，镜头聚焦作品并展开鉴赏文字。
- 作品说明支持“上一幅 / 下一幅”，`Esc`、`Q` 或右上角关闭。
- 拖拽环视，滚轮缩放；方向键环视，`R` 重置视角，`E` / `Enter` 查看当前作品。
- 点击“启用手势”后再申请摄像头权限；失败时自动回退到键盘和鼠标，不阻塞展厅。
- 门扇以闭合状态展示，门柱与门顶栏共同校验入口接缝。
- 长案与书架均移到侧后场，中央通道和北墙主视线保持空旷。
- 三幅画统一高度与上沿，中央《五牛图》使用横向长卷画框，左右两幅保持完整视野。
- 北墙使用暖白粉墙、深木踢脚、轨道射灯和格栅天窗，不再使用深色“黑板”背景。
