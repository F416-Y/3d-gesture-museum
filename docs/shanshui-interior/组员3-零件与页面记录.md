## 页面验收

- 初始相机：`(0, 1.68, 4.35)`，朝向北墙三联画。
- 可行走边界：`x=-6.98..6.98`，`z=-4.98..5.00`。
- 柱础、两侧石凳均有碰撞限制；相机会停在边界内，不穿墙、不掉出地面。
- 入口正视、三联画、柱网、侧窗和天窗共用同一套 Three.js 初始化与 GLTFLoader。
- 当前合并版仍支持桌面端拖动环顾与 `WASD`/方向键移动；这与 hush.gallery 的固定朝向参考不一致，列为组员3的后续功能修正。
- 组员3后续需改为固定朝向，只保留左右切换画作、点击/E查看、Q/Esc关闭；零件预览页保留 360° 旋转。
- 页面入口：`/shanshui.html`
- 页面唯一跨页入口：`返回园区` → `/index.html`

## 构建与预览

```powershell
npm run dev
# 打开 http://127.0.0.1:4173/shanshui.html
```

```powershell
node scripts/build-shanshui-parts.mjs
```


## 已知情况

- 当前环境未安装 Blender。四个零件没有使用 Hyper3D 初稿，而是由 `scripts/build-shanshui-parts.mjs` 用可复现的 Three.js 几何生成，并通过 WebGL 零件预览完成 360° 检查。
- 零件材质是内置 PBR 材质，没有外部贴图依赖；因此 GLB 无贴图丢失风险，但木纹与风化细节比 Blender 贴图流程更克制。
- 当前主参考图位于 D 盘外部项目目录，不直接提交仓库；组员需从约定路径读取，避免继续使用过时历史图。
