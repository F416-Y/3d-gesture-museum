## 三、出图之后怎么用

1. 平面图先定：比例、动线（南门 → 中轴 → 台阶 → 门厅 → 展厅 → 西侧连廊）看一遍是否合理。
2. 立体图照着平面出：把选中的平面图当参考图（垫图权重中等），避免"平面与立体对不上"。
3. **图只指导外观打磨，不动接缝坐标**：改材质、灯光、屋顶造型可以直接改；要动墙/门/展台位置，按 `docs/组员1-结对方案.md` 的规则提前公告。
4. 改完 `scene.js` 后跑一次冒烟测试，确认射灯、热点、碰撞体没被改坏：

```bash
node scripts/smoke-scene.mjs
```
