## 六点五、渲染口径（改外观前必读）

代码里的渲染管线有两条硬约束，改材质/光照时会直接影响观感：

1. **颜色管理已开启**（`main.js`：`THREE.ColorManagement.legacyMode = false`）。
   three r147 默认 legacy 模式会把十六进制颜色当线性值，再经 sRGB 输出**整体提亮**——
   实测：中轴道路材质 `rgb(87,81,74)` 曾被渲染成 `rgb(200,195,185)`、草坪绿被洗成灰绿。
   修好之后道路渲染为 `rgb(168,155,137)`、草坪 `rgb(179,187,134)`。
   **结论**：代码里写的 hex 就是最终色，可以放心按色板取值。
2. **已开 ACES 色调映射**（`main.js`：`toneMapping = ACESFilmicToneMapping`，曝光 1.0）。
   它把超过 1.0 的高光压回来，避免地面过曝成死白。调光照时不要靠"加光强"提亮，
   优先调曝光 `toneMappingExposure`。

> 自查命令（离线即可跑，不需要打开浏览器）：

```bash
node scripts/smoke-scene.mjs
```
## 七、出图之后怎么用

1. 先 P1→P2→P5→P6 定比例与整体关系；再用 P3/P4/P7/P8/P9/P10 补空旷感；最后 P11 判断整体是否平衡。
2. 立体图请把选中的平面图当**参考图（垫图）**，避免"平面与立体对不上"。
3. 图只指导外观打磨：**改材质、灯光、装饰可以直接改**；要动墙 / 门 / 展台这些坐标，按 `docs/组员1-结对方案.md` 提前公告。
4. 改完 `scene.js` 跑一次冒烟测试，确认射灯、热点、碰撞体没被改坏：

```bash
node scripts/smoke-scene.mjs
```
