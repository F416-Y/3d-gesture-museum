# 组员4 · 人物厅内饰与零件交付说明

> 页面：`public/renwu.html`  
> 分支：`feature/renwu-interior-4`  
> 浏览器测试：`http://localhost:5173/renwu.html`

## 一、完成内容

- 人物厅改为独立 Three.js 页面，不加载外景、桥湖和其他展厅。
- 按 `pedestal → warrior → horse → stone-lion → bronze-ding` 顺序接入五件 GLB。
- 提供固定机位：全景、展台基座、将军俑、马踏飞燕、石狮、青铜鼎、背面检查。
- 相机固定在展厅内部，拖拽与缩放不会进入外景。
- 挂画位于北墙高处，展品位于中景和近景，控制观察距离避免互相遮挡。
- 未修改 `index.html`、公共漫游、其他展厅页面或桥湖坐标。

### 原点与朝向约定

- 页面加载时会自动把每件模型缩放到目标高度/最长边，并把包围盒底面中心归到落点。
- 新建 `pedestal.glb` 的建模原点为底面中心，正面朝 `+Z`；总高 1.5m。
- 其余四件沿用项目现有 GLB；最终页面朝向以上表中的 Y 旋转为准。

## 三、浏览器验收结果

- 五件 GLB 全部加载成功：`pedestal / warrior / horse / stone-lion / bronze-ding = true`
- 页面脚本错误：0
- 主要展品最小水平中心间距：**3.96m**
- 相机位置被限制在 `x,z ∈ [-8.1, 8.1]`、`y ∈ [0.95, 3.9]`，不会串到外景
- 入口机位能同时看到中央马踏飞燕、左右展品和北墙挂画

## 五、已知问题

1. 当前机器未安装 Blender，因此五件模型的 360° 检查图使用项目同款 Three.js/WebGL 四向实拍，而非 Blender 渲染图。
2. `pedestal` 在现有资产中没有独立单体参考图，已按 manifest 的 1.5m 尺寸和“石质下裙 + 深木台身 + 铜箍台面”要求程序化生成。
3. 远端缺少 `assets/models/rodin-ring-corridor.glb` 的 LFS 对象；本页面不引用该文件，不影响人物厅运行。
