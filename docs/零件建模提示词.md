## 四、生成方式说明

- **文生图 → 图生3D**：先按上面的提示词生成一张纯白底单件图，再图生 3D。适合没有现成参考图的零件。
- **参考图直出**：直接拿 `docs/reference-images/components/xuting/` 里的单件图做输入，最忠实、最省额度。
- **四视图 → 多视角**：单张正立面缺深度信息，先扩成四视图再做多视角重建。实验证明比单图直出明显更像实物（门柱：单图出横梁，四视图出竖柱）。
- **尺寸**：生成后统一归一化到 1m 包围盒，落地时按 `sizeM` 缩放，所以提示词里不必写尺寸。
- **压缩**：`node scripts/parts-check.mjs` 会把原始 GLB 压缩（贴图降采样 + 量化）并实测加载。
