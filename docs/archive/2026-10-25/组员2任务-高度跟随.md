# 组员2 任务卡 · 高度跟随（新布局的序厅高台）

## 背景

新布局里**序厅是 1.2m 高台**，南侧有**六级踏跺**（z 34.9~36.7，每级 0.2m）。
`player.js` 现在是平面移动（`pos.set(sp[0], eyeHeight, sp[2])`，y 固定 1.7）——
玩家会**直接穿进台基**，站在台基上时视点却还在地面高度。

组长已决定：**由你做高度跟随**（而不是把台基登记成障碍绕行）。

## 我已经给你准备好了接口

外观侧在 `js/scene.js` 里实现了 `terrainHeightAt(x, z)`，并挂在 `MuseumScene` 上：

```js
window.MuseumScene.terrainHeightAt(x, z)   // 返回该点的地面标高（米）
```

实测：

| 位置 | 坐标 | 返回 |
|---|---|---|
| 台阶外（出生点） | (0, 38) | 0 |
| 第六级（最低） | (0, 36.7) | 0.2 |
| 台阶中段 | (0, 35.8) | 0.8 |
| 第一级（最高） | (0, 34.95) | 1.2 |
| 台基上 | (0, 29) | 1.2 |
| 庭院 | (0, 16.7) | 0 |

覆盖范围：
- 序厅台基：`x ∈ [-11, 11]`、`z ∈ [24.5, 34.5]` → 1.2m
- 南入口六级踏跺：`x ∈ [-7, 7]`、`z ∈ [34.7, 36.9]` → 1.2 / 1.0 / 0.8 / 0.6 / 0.4 / 0.2
- 其余地方 0

## 你要改的

`js/player.js` 里，视点的 y 不要再用固定 `eyeHeight`，改成：

```js
var ground = (window.MuseumScene && window.MuseumScene.terrainHeightAt)
  ? window.MuseumScene.terrainHeightAt(pos.x, pos.z) : 0;
/* 上升/下降做插值，避免上下台阶时画面瞬移 */
eyeY += (ground + eyeHeight - eyeY) * Math.min(1, delta * 8);
pos.y = eyeY;
```

（变量名按你现有实现调整；关键是**每帧查一次标高 + 插值平滑**。）

## 验收标准

1. 从出生点 (0, 38) 往北走，上六级台阶到台基（0, 29）：**画面平滑抬升 1.2m，不穿模、不瞬移**
2. 站在台基上：视点高度 = 1.2 + 1.7 = **2.9m**（抬头能看到序厅屋顶内侧）
3. 从台基往南走下台阶：平滑下降回 0
4. 台基**南北两侧**都要能上下（北侧是双廊那四步石阶，标高按原型另有台阶；如果走不通，先把南侧做通）
5. `node scripts/smoke-scene.mjs` 仍全绿；`config.player.speed` 建议同时从 2.4 提到 **3.0**（园区从 88×88 变 100×80，走完要 40 秒太慢）

## 顺带

- 碰撞检测逻辑不用动（读 `obstacles`），但要注意：**台基本身不要登记成障碍**，否则高度跟随就白做了
