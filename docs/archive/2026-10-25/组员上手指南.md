## 一、环境准备（每人只做一次）

### 1.1 安装 Node.js

到 [nodejs.org](https://nodejs.org/) 下载 **LTS 长期支持版**（推荐 20.x / 22.x），安装时全部下一步即可。

装完在终端检查：

```bash
node -v   # 应输出 v20.x.x 或 v22.x.x
npm -v    # 应输出 10.x.x
```

### 1.2 克隆仓库

```bash
git clone https://github.com/F416-Y/3d-gesture-museum.git

cd 3d-gesture-museum
```

### 1.3 安装依赖

```bash
npm install
```

> 依赖较大，第一次可能要 1~3 分钟。如果卡死，喊组长开代理或换 npm 镜像。

### 1.4 启动项目

```bash
npm run dev
```

终端会显示本地地址，例如 `http://localhost:5173`，浏览器打开即可。

### 1.5 配置 Supabase（有登录/收藏/评论需求时再配）

组长会提供 `VITE_SUPABASE_URL` 和 `VITE_SUPABASE_ANON_KEY`。复制模板：

```bash
cp .env.example .env.local
```

然后编辑 `.env.local` 填入对应值。不填也能跑，只是用户相关功能不可用。

## 二、Git 每日流程（最重要）

> 只想尽快开工？直接看 [流程速查卡.md](./流程速查卡.md)——一页纸，照着敲不会错。

**2.1 确认推送守卫已启用**

```bash
git config core.hooksPath .githooks
```

**2.2 开工前——先同步 main（90% 冲突都是因为这步漏了）**

> 仓库只有 `main` 这一条主线，它也是默认分支：**克隆下来就在 `main` 上，不用切分支**。
> 日常开发在各人的 `feature/*` 上，但每次开工前先把 `main` 拉到最新。

```bash
git switch main
git pull origin main
```

**2.3 每个子任务新开一条分支（重要）**

大任务拆成小任务，**一个子任务 = 一条分支 = 一个 PR**。这样做的好处：PR 小到组长审得动；哪个子任务做坏了只回滚那一条分支，不牵连别的；冲突面小。

**命名规则**：`feature/<模块>-<子任务>-<组员序号>`

```bash
git switch main && git pull
git switch -c feature/scene-collision-1     # 例：组员1 的「碰撞体登记」
```

**2.4 写代码（只改你的文件）**

**2.5 提交并推送**

```bash
git add -A
git commit -m "feat(scene): 一句话描述你做了什么"
git push -u origin feature/你的分支名
```

**2.6 提 Pull Request：你的 feature 分支 → main**

去 GitHub 仓库网页 → Pull requests → New PR → `base: main`（默认就是 main，不用改）← `compare: feature/你的分支名` → 简单写两句改动说明 → Create。提完**在群里贴链接 @组长**（只提 PR 不说话，PR 会一直挂着），然后等 review，**不要自己点 Merge**。合并后**分支保留不删**（留作提交记录），但下一个子任务要**从最新的 main 新开一条分支**。

**2.7 合并之后：分支保留，但不要复用**

PR 一被合并，这条分支的使命就结束了——删掉它，下一个子任务从 `main` 重新切：

```bash
git switch main && git pull
# 分支保留（不删）——它已经合并进 main，记录留在提交历史里
# 本地想留着看提交记录就留着，想删也行：
# git branch -d feature/scene-collision-1
```

> 别在同一分支上接着做下一个子任务：PR 会变成大杂烩，review 不动，出问题也没法单独回滚。

## 六、常见问题速查

**Q：我不小心改了别人的文件怎么办？**

A：先别提交。用 `git checkout 文件名` 恢复成仓库版本，再重新改自己的文件。

**Q：npm install 报错 / 卡住？**

A：让组长检查代理，或换 npm 镜像：

```bash
npm install --registry=https://registry.npmmirror.com
```

**Q：我按 W 走不动？**

A：先看画面右下角 hall-label 是否显示，再看浏览器控制台有没有红色报错。最常见原因是 `MediaPipe` 加载失败导致 `main.js` 初始化中断——刷新重试即可。

**Q：收藏/评论功能显示「未配置 Supabase」？**

A：你还没填 `.env.local`，或者填错了。找组长要正确的 Project URL / Anon Key。

**Q：我要临时看别人的分支怎么切？**

A：可以 `git switch feature/xxx` 查看，但**不要在自己的分支 merge 别人的分支**，一切以 `main` 汇总为准。
